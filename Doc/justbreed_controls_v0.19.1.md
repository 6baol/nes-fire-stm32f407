# Just Breed 操作调整 v0.19.1

2026-11-19。用户反馈推住摇杆时 KEY2 确认不响应、摇杆操作不顺手。本轮离线修改并生成 `NesFire_v0.19.1-controls-preview.hex`，没有下载、复位、注入按键或写物理 SD 卡。板上仍为用户烧录的 v0.19。

## 观察和处理

运行中只读采样 24 次，当前 Mapper 为 5、游戏运行中，逻辑计数均约 39 Hz；完整绘制为 57.6～60.2 ms。摇杆在采样期间已标定且健康，ADC 错误计数没有增长；当时没有按键按住，不能用这批数据证明每一种实体组合按键都能到达游戏。

新增适配仅匹配当前 Just Breed 日本版标准化 ROM 的 CRC32 `60579AF2`、大小 786,448 字节和 Mapper 5，不按“所有 MMC5”统一处理，也不依赖可修改的菜单名称。其他镜像及汉化补丁不会自动启用。

- 模拟摇杆转为四方向：以主轴为准，轴切换需超过 160/1024 的优势；进入阈值 360/1024、保持阈值 220/1024，减少斜推串行与边缘抖动。
- A / B / Start 按住时，暂时不向游戏发送方向；按钮本身独立保留，KEY2 仍是 A，KEY1 仍是 B。
- 松开确认键即可继续使用当前推杆方向，不要求重新回中或重新标定。加载游戏和返回库时清除方向历史。
- 游戏库及 Settings 使用原有输入；非本镜像的方向、A+B 组合保持原路径。
- 本次没有修改既有 20 ms 实体按钮消抖。极短轻点、其他场景的漏按仍须实机复测。

实际日文 ROM 的姓名页对比中，原生 `右+A` 与适配后的 `A` 都写入了同一个姓名字符，但后续光标位置不同。这说明不能将所有漏按归因于 GPIO 冲突；本次通过明确的确认优先策略减少方向干扰，尚不能宣称已复现并解决用户遇到的所有场景。

## 性能

MMC5 解码缓存从 4 KiB / 256 项扩大到 64 KiB / 4096 项；标签用 16 位保存，符合当前 CHR ≤256 KiB 的范围。数据仍在外部 SRAM 的 `0x6c000000～0x6c00FFFF`，ROM arena 从 `0x6c020000` 开始，互不覆盖。原始 ROM、8 KiB WRAM 和存档格式未改变。

对同一城镇场景、同样按键与帧数的实际 ARM 对比：

| 指标 | v0.19 | v0.19.1 |
|---|---:|---:|
| 单个绘制帧 ARM 指令数 | 2,741,302 | 2,085,878 |
| 该帧 tile 解码次数 | 1,846 | 2 |
| 画面、CPU PC、CPU RAM、SRAM 哈希 | 与右列一致 | 与左列一致 |

指令数减少 23.91%。测试替换了物理 LCD 提交，不能把这个百分比当作整机提速比例。

Just Breed 还增加按耗时调整绘制间隔：平均成本按 `skip + (draw-skip)/divisor` 估算，目标每逻辑帧 16 ms，间隔限制为 2～8，保留约 0.67 ms 的其他前台工作余量。重画成本较高时降低画面提交频率，优先补齐游戏逻辑；请求的原始 divisor 仍是下限。新计数 `nes_effective_render_divisor` 可供实机检查。无法仅凭该估算保证 60 Hz，烧录后必须重新采样。

## 验证

- 新输入专项：四向滞回、推杆保持时 A/B/Start 优先、松键无需回中、真实 GPIO 和原消抖、菜单隔离、按 ROM CRC 选配置、跨游戏恢复及绘制间隔计算。
- 实际姓名输入对比与缓存前后画面/CPU 状态一致性。
- 12 个回归脚本：原生输入、调度、RPG 适配、MMC5、七款 SD 库、双槽存档、音频输出/静音、电容键、菜单、旧游戏操作及 Wizards 连续画面，均通过。
- 全量编译 0 errors / 0 warnings；Code 98,720 / RO 56,348 / RW 280 / ZI 90,480 字节；BIN 156,672 字节。

报告：`Release/controls_v0.19.1_report.json`。`Release/input_readonly_v0.19.json` 是旧固件的只读基线；本版 `hardware_tested=false`。

## 使用

先长按 SW 返回游戏库，完成当前存档写卡，再手动烧录新版。SD 卡和 ROM 无需重拷，已有 Just Breed 存档仍使用同一 ROM CRC 和 8 KiB 格式。

烧录后重点验证：推住方向再按 KEY2 是否能确认；确认时是否还会串到旁边菜单；松开 KEY2 后能否直接继续移动；城镇移动、音乐节奏和帧率是否改善。实机效果未确认前，保留 `Release/NesFire_v0.19-mmc5-preview.hex` 作为已验收的原版固件。
