# v0.22：卡上游戏库、中文名与翻页

本版把 SD 游戏库从“少量英文游戏”扩到“几百个 ROM、含中文名”。所有数据都在卡上，
固件只保留窗口和解析代码。

## 卡上布局

```
F:\NES\
  <任意名称>.nes / .fds          顶层游戏
  <子目录>\<任意名称>.nes         递归一层到三层
  <游戏>.COV                     可选封面（与 ROM 同名）
  FONT.MAP / FONT.HZK            16×16 中文字模（约 310 KB）
  TITLES.DB                      可选：指纹 → 正式名
  SAVES\                         存档（固件创建）
  _LEGACY\                       以 _ 或 . 开头的目录会被完全忽略
```

目录规则：只扫 `NES` 及其子目录；文件名/目录名可以是 UTF-8（中文）；
以 `.` 或 `_` 开头的目录和 `SAVES` 目录不扫。**想放旧文件但不想出现在菜单里，加个下划线前缀即可。**

## 目录表（CATALOG.IDX）

- 定长 272 字节记录：相对路径 160 B（UTF-8）、显示名 96 B、大小、FAT 时间戳、FDS 标志。
- 卡上最多 1024 项；RAM 只保留 4 条记录的窗口（约 1 KB）和 8 KB 存档暂存。
- 开机先做一次 `f_readdir` 计算目录快照（名字+大小+时间），与表头一致就直接用表，
  **不再打开任何 ROM**；不一致才重建。
- 重建时把旧表复制到外扩 SRAM，按名字哈希合并：没有变化的条目直接沿用显示名，
  只有新增或改动的文件才会被打开。
- 缓存只用于加速，选中 ROM 时仍会读头校验；文件被删/换会报 `SD FILE MISSING` 而不是跑错数据。
- 目录表损坏或缺失会自动重建，不会导致无法开机。

## 中文名

- FatFs 用 UTF-8 长文件名（`FF_LFN_UNICODE 2`，单段最多 128 字节）。
- 菜单字号是 16 px：ASCII 用 Flash 里的 8×8 字模放大 2 倍，中文用卡上的 16×16 点阵。
  两者都是 16 px 一格，所以中英混排、按字符换行都能对齐。
- 字库由 `tools/make_cjk_font.py` 从系统宋体生成（GB2312 全集 7445 字），
  固件二分查找 `FONT.MAP` 得到字模序号，再读 `FONT.HZK` 的 32 字节；带 256 项字形缓存。
- 卡上没有字库时，中文显示为 `?`，不会崩溃。

## 标题字典（TITLES.DB，可选）

```
NESDB1
<8 位十六进制指纹>\t<标题>
```

指纹 = `crc32(文件大小 LE32 ‖ 前 4 KiB ‖ 后 4 KiB)`，由 `tools/make_titles.py` 从
No-Intro DAT 或 `Roms/roms.json` 生成。

**注意代价**：存在字典时，重建目录会为每个 ROM 打开文件算指纹。几百个文件时首次开机
可能多花十几秒。如果文件名本身已经是可读标题（例如这批中文 ROM），建议**不要放字典**。

## 菜单

- 条目计数改为 16 位，显示 `当前/总数`，三位数也放得下。
- 上下选择、**左右按 5 条翻页**；两个轴各自独立回中武装，斜推不会同时触发。
- 每个选中项读一次封面（约 30 KB）。

## 上限

| 项目 | 值 |
|---|---|
| 条目数 | 1024 |
| 相对路径 | 160 字节（UTF-8） |
| 显示名 | 96 字节（UTF-8） |
| 单个 ROM | 普通 640 KiB / MMC5 896 KiB |
| 子目录深度 | 3 层 |
| 封面 | 128 KiB 以内（读入 ROM arena 前 128 KiB） |
| 字库 | FONT.MAP ≤ 64 KiB；FONT.HZK 固定 8836×32 B |

## 验证

- `Tests/test_sd_scan_utf8_arm.py`：子目录、UTF-8 名、45 项、`_`/SAVES 排除、子目录内加载、
  二次开机复用目录表。
- `Tests/test_cjk_lcd_arm.py`：中文 UTF-8 名进入目录；`FONT.MAP` 查找与 `FONT.HZK`
  位图在 LCD 上逐像素一致；ASCII 仍用 Flash 字模；缺字库退化为 `?`。
- `Tests/test_sd_library_arm.py`：目录表命中/失效/损坏、加载校验、封面、70 项上限、
  TITLES.DB 命中与损坏回退。
- `Tests/render_menu_arm.py --sd`：菜单排版、封面、翻页状态、设置页回归。
- `Tests/test_sd_saves_arm.py`、`test_discrete_mappers_sd_arm.py`、`test_rpg_controls_arm.py` 通过。

以上为本地 ARM 仿真；实机首次插卡的开机时间与中文观感需要板上确认。
