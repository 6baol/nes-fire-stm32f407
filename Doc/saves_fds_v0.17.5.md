# SD 电池存档、FDS 换面及扩展音源 v0.17.5

日期：2026-11-18。默认 SD 工程，用户自行烧录。本版保留 v0.17.3 的 NMI 画面修正及 v0.17.4 的耳机／扬声器／静音选择。

## 使用方法

### 电池存档

带 battery 标志的普通卡带游戏，其 8 KiB PRG RAM 会在长按 SW 1.5 秒返回游戏库时保存；再次启动同一 ROM 自动恢复。游戏运行中不读写 SD。先回菜单，看到 SAVE OK 后再断电。内容未变化时不重复写卡。

只在默认 SD 游戏库模式启用，不是即时存档：不能保存任意游戏的 CPU/PPU/关卡快照，也不写 FDS 磁盘。当前 Metroid 美版原生使用密码，不能靠设置 battery 标志将它变成另一种存档方式；测试使用独立自制电池卡带，未修改用户游戏。

目录 `/NES/SAVES` 自动建立，无需重拷已有 ROM、封面或索引。ROM 的 CRC32 是八位文件主名，两个槽为 `XXXXXXXX.SV0`、`XXXXXXXX.SV1`。不以游戏列表序号或标题作为标识，因此菜单排序、标题和文件短名改变不影响同一内容的存档。

每槽 8220 字节：28 字节 NSV1 头加 8192 字节 PRG RAM。小端头字段依次为 magic、ROM CRC32、ROM 长度、RAM 长度、generation、RAM CRC32、头部 CRC32。读取时校验全部元数据及 CRC，选择最新有效槽，generation 支持自然回绕。写入只替换非活动槽，f_sync、关闭、读回验证后才提交新的活动槽。

若最新槽损坏但备份有效，恢复备份并提示 SAVE BACKUP LOADED；两槽都无效则报错，不静默覆盖。写入失败时保留待保存 RAM，返回菜单显示原因，启动其他游戏前重试，仍失败则阻止替换内存。双槽可降低单次写入中断导致丢档的风险，但不承诺整个 FAT 文件系统在任意物理断电条件下原子更新。

底层 FatFs 已从只读改为读写；写卡同样使用内部 SRAM 对齐的 512 字节中转、单扇区传输、最多两次尝试，并等待卡结束编程。没有格式化逻辑，存档路径仅为上述目录和槽文件；ROM、封面、BIOS、索引以及其他目录不作为写入目标。

### FDS 换面

多面 FDS 游戏运行时，按住 Select（电容键）并拨摇杆左／右，切换上一面／下一面。顺序为 1A、1B、2A、2B……，首尾循环。保持方向不会连续换面，释放方向后可再次操作；组合键被换面功能消费，不再传给游戏。

驱动先向 BIOS 呈现无盘状态，约半秒的模拟 CPU 时间后插入目标面。此期间继续运行 CPU，不复位 CPU、PRG RAM、APU 或游戏；磁盘源镜像和合成流都已在 SRAM，不访问 SD。屏幕底部显示目标盘面和 INSERTING / INSERTED；合成失败则显示 INSERT FAILED。正在插入时不接受另一项请求。

镜像仍最多八面，必须通过既有 FDS 结构校验，单面合成流限于 128 KiB。磁盘保持写保护，未实现 FDS 写盘存档或全部磁盘保护行为。当前 SMB2 文件只有一面，游戏内保持原来的 Select/方向输入，不显示换面操作。

### FDS 扩展音源

新增 2C33 的 64 点／6 位波表通道、音量及调制包络、主包络速度、调制表／计数器及主音量，混入现有 11025 Hz NES PCM。包括波表写入门控、播放位置读回、写表期间保持输出、直接音量零立即静音，以及常用增益/相位读回。

CPU 寄存器状态与音频消费者分离，写入通过现有时间戳 APU 队列有序应用，避免音频 DMA 与 CPU 直接改动同一音源状态。波表/调制相位使用 16 CPU 周期步进和固定点频率；包络与调制对音频的影响按输出采样近似，不宣称逐周期准确的 2C33 乘法流水线、全部调试寄存器或模拟滤波特性。

硬件参考：[NESdev FDS audio](https://www.nesdev.org/wiki/FDS_audio)、[FDS 寄存器](https://www.nesdev.org/wiki/User:TakuikaNinja/FDS_Registers)。

## 本地验证与限制

Keil 全量构建零错误／零警告，BIN 149504 字节。主要测试实际执行当前 AXF 的 ARM 指令：

- `test_sd_saves_arm.py`：自制电池卡带＋实际 FatFs＋独立 FAT32 块设备；双槽、断电式冷加载、无变更零写入、坏新槽备份恢复、两槽损坏拒绝、写失败及部分写失败、切换游戏保护及重试。
- `test_sdio_polling_arm.py`：实际驱动包装，模拟 HAL；读取／写入内部对齐中转、扇区边界、有限重试、初始化回退与同步。
- `test_fds_sides_arm.py`：双面测试镜像的 B 面字节、可观察取盘／插盘、CPU/RAM 保持、真实输入组合键、过滤／防连换、首尾循环与卸载取消。
- `test_fds_audio_arm.py`：寄存器门控、读回、包络/停止、输出保持/立即静音、主音量比例、调制表与时间戳；实测合成基音约 439.98 Hz，静态调制约 549.98 Hz。
- 现有五款 SD 路径、SMB2 BIOS 到 1-1、Wizards 连续画面、菜单与 Settings、输出路由、DMA 静音、NMI 及 60 Hz 调度回归。

实体 SD 卡写入、商业双面游戏的换面流程、扩展音源的板上性能和耳机／扬声器听感尚未验收。初始开发仅做离线验证；用户随后授权通过仿真器烧录，149504 字节完整 Flash 读回一致，之后要求恢复离线工作，未继续做板上功能验证或读写实体卡。双面测试只修改私有内存镜像的盘面标识，未新增游戏或改变原始文件。
