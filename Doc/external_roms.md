# 外部 ROM 导入与默认海报

本文面向最终用户：把电脑上的 `.nes` / `.fds` 放进 SD 卡，处理 Hack/汉化版本，
并在没有 `.COV` 封面时让游戏机自动用开始画面当海报。全部操作都有图形界面，
不需要命令行。

## 1. 启动导入助手

- Windows：双击 `tools/NesImportGUI.bat`。
- 或者：`python tools/nes_import_gui.py`。

首次使用需要 Pillow（只有生成/预览封面才用得到）：

    pip install pillow

程序启动时会自动扫描盘符，找到 `X:\NES` 后填入“SD 卡 NES 目录”。
如果没找到，手动点“浏览…”选择即可。

## 2. 导入 ROM

1. “ROM 来源”选择电脑上放 ROM 的文件夹；会递归扫描子目录。
2. “SD 卡 NES 目录”选择卡里的 `NES` 文件夹。
3. 点“扫描”。表格会显示：
   - **改版 = 是**：文件名带 `(Hack)`、`(Kaizo)`、`(Translation)`、`(T-Eng)`、
     `(Beta)`、`(Proto)`、`[h1]` 等标记，或位于 `hacks/` 目录。
   - **封面 = 缺**：同目录没有同名 `.COV`。
   - **重复 = 完全相同 / 同名**：按 SHA-256 或英文标题判断。
4. 选中一个或多个游戏（Ctrl/Shift 多选），点“导入选中”。
   - 普通 ROM → `NES/imports/`
   - Hack/汉化 → `NES/hacks/`（与普通 ROM 分开，去重时受保护）
   - 同名文件不会覆盖：内容相同则跳过，不同则自动加 `(2)`、`(3)`
   - 勾选“同时导入同名 .COV”时，已有封面会一起复制

导入完成后，程序会询问是否重建目录。选择“是”会把 `CATALOG.*` 改名为 `.OLD`，
游戏机下次开机自动重新扫描。也可以稍后在“维护”页操作。

## 3. 默认海报：开始画面

**没有 `.COV` 的 ROM，第一次启动时会自动生成海报。**

固件在游戏加载成功后等待约 180 帧（约 3 秒），让标题/开始画面显示出来，
然后把当前帧写成同目录同名的 `<ROM 名>.COV`：

- 格式：NCV1，256×240，8 位索引，64 色 NES 调色板；
- 如果画面还是全黑/单色，会继续等待并重试，最多约 900 个绘制帧；
- 写入失败不影响游戏，菜单继续显示“NO COVER”；
- 不覆盖已有 `.COV`，也不触发目录重建。

因此导入 Hack、汉化或冷门 ROM 时，**可以完全不管封面**：先玩一次，
退回菜单后就有海报了。

### 手动指定封面

“封面”页可以：

- 选中游戏 → “用图片生成封面…”：选一张 PNG/JPG，建议 256×240 的 NES 截图；
- “删除封面（首玩自动截取）”：删掉 `.COV`，下次启动重新自动截取。

封面编码为 NCV1，调色板为 RGB565，固件不需要运行期解码器。

## 4. 维护

| 功能 | 说明 |
|---|---|
| 检查重复（只读） | 按英文标题分组，显示会保留/移除哪些版本 |
| 执行去重… | 把多余版本移到 `NES` 外的 `_dedup_removed_*`，不直接删除 |
| 重建目录 | `CATALOG.*` → `.OLD`，下次开机重扫 |
| 按英文名排序 | 目录重建后运行；保留每条记录的拼音字段 |
| 填充拼音索引 | 给中文标题补拼音，方便搜索 |

去重规则：同英文标题保留一个，优先级
World > USA > Japan,USA > Europe > Japan；同区域优先新 Rev；
避开 Collection/Publisher 变体。**Hack、汉化、Beta、Proto、Demo、
Bootloader、Pirate、Homebrew、`[h]` 以及 `hacks/` 目录永远不参与去重。**

## 5. 卡上布局

    NES/
      CATALOG.IDX         固件生成的目录，可重建
      TITLES.DB           标题字典（可选）
      PREFS0.DAT/1.DAT    收藏与最近记录
      SETTINGS.BIN        横竖屏、音量、输出
      imports/            导入助手放入的普通 ROM
      hacks/              导入助手放入的 Hack/汉化
      famicom/            原有分桶目录
        00/ 01/ ...       每个桶约 100 个 ROM + 同名 .COV

固件递归扫描最多 4 层，因此 `imports/`、`hacks/`、`famicom/00/` 都能识别。

## 6. 常见问题

**导入后菜单里没有新游戏？**
在“维护”页点“重建目录”，然后让游戏机开机扫描一次。

**新游戏没有海报？**
先玩一次，退出后自动生成；或在“封面”页手动指定图片。

**去重会不会删掉我的 Hack？**
不会。带改版标记或位于 `hacks/` 的文件被整体排除，不会被移动。

**排序后又乱了？**
每次重建目录都会恢复扫描顺序，需要重新运行“按英文名排序”。

**能直接删 ROM 吗？**
可以用资源管理器删除；更好的做法是先用“检查重复”确认，再把不需要的版本
移到隔离目录，避免误删存档和收藏记录。
